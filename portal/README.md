# Imani Vision — Portal

Next.js 16 developer portal: sign-up/sign-in, API key management, docs, usage, and the Live Test demo. Runs on **http://localhost:3001**.

```bash
npm install
npm run dev      # http://localhost:3001
```

Needs `portal/.env.local` and a running gateway. Setup, environment variables and troubleshooting: **[../documentation.md](../documentation.md#part-a--getting-started)**. How the portal works: [§4.3](../documentation.md#43-portal-portal).
